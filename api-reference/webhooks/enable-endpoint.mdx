> Enable a disabled webhook endpoint.

`POST /api/v1/widgets/webhook-endpoints/:endpointId/enable-endpoint`

## Parameters

### Path

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `endpointId` | `string` | Yes | The endpoint ID |

## Request example

```shell
curl --request POST 'https://payments.bleepay.com/api/v1/widgets/webhook-endpoints/wh_abc123/enable-endpoint' \
  --header 'Authorization: Bearer <business_token>' \
  --header 'Content-Type: application/json' \
  --data '{}'
```

## Response

Returns HTTP 200 with an empty body.
