> Reserve and redeem a voucher to request a payment, in a single call.

`payment.request`

Composite tool: it looks up the declared account, reserves the voucher from the payer's code, and redeems it with the expected payment terms. On success the voucher is `REDEEMED` — the payment is requested but not yet settled; the payer must confirm in their wallet.

**Actor:** Merchant — requires an API key.

## Input

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `code` | `string` | Yes | Six-digit code from the payer. |
| `accountId` | `string` | Yes | A declared account of the merchant. |
| `currency` | `string` | Yes | Currency symbol — must be one of the account's declared currencies. |
| `amount` | `string` | Yes | Positive decimal amount as a string (e.g. `"23.42"`). |

## Output

| Field | Type | Description |
| --- | --- | --- |
| `voucherId` | `string` | Redeemed voucher identifier |
| `status` | `string` | `REDEEMED` |
| `expiresAt` | `string` | ISO 8601 expiry timestamp |

### Example

```json
{
  "voucherId": "vch_482916",
  "status": "REDEEMED",
  "expiresAt": "2026-08-20T12:02:00.000Z"
}
```

The payment is not settled until the voucher reaches `RESOLVED`. Check with `payment.status`.
